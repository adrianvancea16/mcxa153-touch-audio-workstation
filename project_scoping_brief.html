2. Project Summary & Objectives

A dual-mode embedded audio workstation built on the NXP FRDM-MCXA153 platform, featuring a 2.4-inch ILI9341 SPI TFT LCD with integrated resistive Touchscreen and SD Card storage. The system operates in two main firmware modes selected via an intuitive graphical Touch UI or a wireless web interface:

  • Operating Environment: Laboratory / Benchtop / Handheld
  • Main Behavior: LPADC audio sampling, 60 FPS FFT rendering & oscilloscope on 2.4" TFT LCD, bare-metal SD Card WAV recording, Touch Keyboard & modulation pad synthesizer with internal DAC output, and ESP8266 Wi-Fi local web server.

3. Project Ambition Tiers

Tier Description Key Features
Core Student Version Basic audio spectrum analyzer & oscilloscope. LPADC audio sampling (40 kHz), CMSIS-DSP 256-point FFT, spectrum bar graph & waveform on ILI9341 TFT LCD, button mode toggle.
Recommended Version Dual-mode Touch Audio Workstation with SD Card recording and internal DAC synthesizer. Dual-mode Touch UI, bare-metal WAV recording to SD Card (FatFS/SPI), touchscreen piano synthesizer with filters, and internal DAC output.
Advanced Extension IoT Connected Workstation with ESP8266 local web server. ESP8266 UART Wi-Fi hosting local web server, remote browser dashboard for telemetry, and wireless mode/parameter control.

5. Risks & Assumptions

  • A-001: ILI9341 LCD, Touch, and SD Card slot share the SPI bus using separate CS lines.
  • A-002: DAC output uses a 1k resistor in series with Tip/Ring to protect the MCU from headphone load impedance.
  • Risk 1: SPI bus bandwidth contention between LCD rendering, Touch polling, and SD writing.
  • Risk 2: ESP8266 peak current draw causing 3.3V voltage dip during Wi-Fi transmission.
