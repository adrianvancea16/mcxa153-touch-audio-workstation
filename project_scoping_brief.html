2. Project Summary & Objectives

A portable dual-mode embedded audio processing instrument built on the NXP FRDM-MCXA153 platform. It features real-time FFT spectrum visualization, audio recording to SD Card, DFPlayer playback, touchscreen piano synthesis, and ESP8266 Wi-Fi telemetry.

  • Operating Environment: Laboratory / Benchtop / Handheld
  • Main Behavior: ADC+DMA audio eesantionare, 60 FPS FFT rendering on 2.4" TFT Touch LCD, FatFS SD Card recording, DFPlayer MP3/WAV playback, and UART Wi-Fi streaming.

3. Project Ambition Tiers

Tier Description Key Features
Core Student Version Basic audio spectrum analyzer rendering live FFT on 2.4" TFT LCD. ADC sampling, CMSIS-DSP 256-point FFT, spectrum bar graph, pushbutton mode toggle.
Recommended Version Dual-mode Touch Audio Workstation with SD Card recording and DFPlayer playback. Dual-mode Touch UI, SD Card WAV recording (FatFS), DFPlayer Mini UART control.
Advanced Extension IoT Connected Workstation with ESP8266 Web Dashboard and Web-MIDI control. ESP8266 UART Wi-Fi bridge, interactive web dashboard, cloud telemetry.

5. Risks & Assumptions

  • A-001: ILI9341 LCD and SD Card slot share the SPI bus using separate CS lines.
  • Risk 1: SPI bus bandwidth contention between LCD rendering and SD writing.
  • Risk 2: ESP8266 peak current draw causing 3.3V voltage dip during Wi-Fi transmission.
