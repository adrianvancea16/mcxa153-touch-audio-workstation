3. Scenarios and User Stories

Scenarios

  • SC-001 (Startup): On power-on, the MCU initializes clocks, SPI display, ADC, and SD Card, rendering the Main Menu on the Touchscreen.
  • SC-002 (Analyzer Mode): User taps "Analyzer", MCU displays real-time FFT spectrum and oscilloscope waveform at 60 FPS.
  • SC-003 (Record Mode): User taps "Record", MCU writes PCM WAV audio data to SD Card via SPI FatFS.
  • SC-004 (Synthesizer Mode): User taps "Synth", MCU displays interactive piano keys; touching keys outputs synthesized tones.

User Stories

  • US-001: As a student, I need real-time FFT spectrum visualization so that I can analyze audio frequencies visually.
  • US-002: As a user, I need a Touchscreen GUI so that I can easily toggle modes and adjust scaling.
  • US-003: As a user, I need SD Card audio recording so that I can save sound samples for offline analysis.

6. Hardware Block Diagram Description

The FRDM-MCXA153 acts as the central hub. Analog audio signals from the MAX4466 mic / AUX jack are fed into LPADC0. The 2.4" ILI9341 TFT display and SD Card slot connect over SPI0 with separate CS lines. DFPlayer Mini and ESP8266 communicate over LPUART1 and LPUART2 respectively. Power is delivered by a 3.3V regulated rail fed from a TP4056 Li-ion charger.

8. Firmware Architecture

Bare-metal superloop architecture with interrupt-driven ADC sampling and DMA transfer. Main loop handles Touch GUI events, CMSIS-DSP FFT execution, display frame buffering, and SD Card I/O flushing.
