3. Scenarios and User Stories

Scenarios

  • SC-001 (Startup): On power-on, the MCU initializes clocks, SPI display, ADC, DAC, and SD Card, rendering the Main Menu on the Touchscreen.
  • SC-002 (Analyzer Mode): User taps "Analyzer", MCU displays real-time FFT spectrum and oscilloscope waveform at 60 FPS.
  • SC-003 (Record Mode): User taps "Record", MCU samples microphone and streams PCM WAV audio data directly to SD Card via SPI FatFS.
  • SC-004 (Synthesizer Mode): User taps "Synth", MCU displays interactive piano keys and XY modulation pad; touching keys outputs synthesized waveforms (sine/triangle) and applies filters, routing output to internal DAC.
  • SC-005 (Wireless Control): ESP8266 hosts a local web page. A user connects via phone/laptop browser to monitor the audio frequency peaks and toggle modes remotely.

User Stories

  • US-001: As a student, I need real-time FFT spectrum and oscilloscope visualization so that I can analyze audio frequencies visually.
  • US-002: As a user, I need a Touchscreen GUI so that I can easily toggle modes and navigate synth settings.
  • US-003: As a user, I need direct SD Card WAV recording so that I can capture ambient sounds bare-metal.
  • US-004: As a user, I need headphone output directly from the MCU's internal DAC so that I can listen to generated synthesizer tones and filtered audio.

6. Hardware Block Diagram Description

The FRDM-MCXA153 acts as the central hub. Analog audio signals from the MAX4466 microphone preamplifier are fed into LPADC0. The 2.4" ILI9341 TFT display, resistive Touch controller, and SD Card slot connect over SPI0 using separate CS lines. The internal DAC drives a 3.5mm headphone jack through a 1kΩ series resistor. An ESP8266 Wi-Fi module communicates over LPUART2 to host a local web server. Power is delivered entirely through standard USB power supplying the FRDM-MCXA153 board, which distributes 3.3V to all external components.

8. Firmware Architecture

Bare-metal superloop architecture with interrupt-driven ADC sampling and DMA transfer. Main loop handles Touch GUI events, CMSIS-DSP FFT execution, display frame buffering, and SD Card I/O flushing. Audio synthesis utilizes a high-priority timer interrupt driving the internal DAC at 16 kHz to guarantee jitter-free audio reproduction.
